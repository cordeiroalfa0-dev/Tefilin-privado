## Código-base reconstruído

O arquivo [`reconstrucoes/Tefilin_codigo_base_reconstruido_v1.1.34.zip`](reconstrucoes/Tefilin_codigo_base_reconstruido_v1.1.34.zip) foi recuperado do `resources/app.asar` presente no pacote portátil da release `v1.0.1`.

SHA-256 do ZIP reconstruído: `9f7664e97f3eb8e93b13f824dc2ebc7acc5aad2d85bec3581955d89729990ffd`

O pacote contém o código legível do processo Electron, migrações, sincronização, preload e o frontend compilado em `dist/`. O frontend original foi publicado como bundle Vite; portanto, os fontes React/TypeScript não compilados e mapas de origem não estavam presentes no executável e não podem ser recuperados fielmente a partir dele. As limitações estão documentadas no `README_RECONSTRUCAO.md` dentro do ZIP.
